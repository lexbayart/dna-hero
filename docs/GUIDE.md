# DNA Hero — Полное руководство пользователя

> Это руководство покрывает все функции приложения. Для тех, кто впервые открывает DNA Hero.

---

## 🖱️ Начало работы

Откройте приложение в браузере. Вы увидите два основных блока:

- **Левая панель** — настройки: ракурсы, освещение, персонаж, погода, износ, повреждения, настроение, стиль
- **Правая панель** — результат: сгенерированный промпт, негативный промпт, кнопки копирования

Сверху — строка с названием «Личное дело» (сохранённый пресет) и кнопкой лога.
Снизу — статус-бар с количеством слов, знаков и токонов.

Каждая секция в левой панели сворачивается/разворачивается по клику на заголовок. Кнопка ⊟/⊞ вверху слева сворачивает/разворачивает все секции одновременно.

## 🎨 Инструменты

### Ракурсы
Определяет, с каких углов будет показан персонаж. Можно выбрать несколько — они появятся в промпте в правильном порядке.

| Выбор | Что делает |
|-------|-----------|
| Спереди 0° | Фронтальный вид, классический анфас |
| Сзади 180° | Вид сзади, спина персонажа |
| Лево 90° | Профиль слева |
| Право 270° | Профиль справа |
| 3/4 · 45° | Три четверти — между анфасом и профилем |
| 3/4 сзади | Три четверти сзади |
| Лицо крупно | Крупный план головы и шеи, лицо занимает 70–80% панели |
| Сверху ↓ | Вид строго сверху (nadir angle, 90°) |

### Формат кадра
Соотношение сторон выходного изображения. Визуальные превью показывают пропорции каждого варианта.

- **4:1** — очень широкий turnaround-лист для нескольких ракурсов в ряд
- **3:1** — широкая полоса, компактнее
- **2:1** — умеренно широкий кадр
- **16:9** — кинематографический формат (выбран по умолчанию)
- **1:1** — квадрат, портрет/аватар
- **2:3** — вертикальный портрет, классическое фото
- **9:16** — формат «история» для мобильных

### Освещение
7 вариантов освещения, каждый генерирует развёрнутое физически-корректное описание:

- **Студия · ровное** — мягкие софтбоксы, без теней (по умолчанию)
- **Студия · 3-точечное** — key 45° right, fill left, rim backlight
- **Лунный свет** — холодный сине-белый, жёсткие тени, ночная атмосфера
- **Лампа тюрьмы** — одна лампа над головой, глубокие тени под глазами
- **Пасмурный день** — рассеянный холодный серый свет
- **Сибирская зима** — плоский холодный белый, без тепла
- **Таёжный свет** — солнечные пятна через хвойный полог
- **Золотой час** — тёплые 3200K, длинные тени
- **Жёсткий боковой** — один источник 45° слева, глубокие тени
- **Допрос · лампа** — лампа МГБ, жёсткий нисходящий свет

### Персонаж
Текстовое поле для описания персонажа. Напишите внешность, одежду, детали — текст попадёт в промпт как есть.

### Пол
- **Не задан** — без указания (по умолчанию)
- **Мужчина** — добавляет блок CHARACTER GENDER: Male в промпт
- **Женщина** — добавляет CHARACTER GENDER: Female в промпт

### Поза
- **A-Pose** — классический референс: руки по сторонам с небольшим углом
- **T-Pose** — руки горизонтально, для риггинга

### Этничность
Мягкий культурный контекст — не меняет внешность, а указывает модели культурный фрейм. 7 вариантов: русский/славянский, украинский, кавказский, среднеазиатский, еврейский ашкеназский, сибирский/бурятский, прибалтийский, татарский/башкирский.

### Возраст
- **Взрослый (25–50)** — базовый (по умолчанию)
- **Пожилой (60–70)** — добавляет описание возрастной анатомии
- **Старик (75–85)** — продвинутая возрастная анатомия
- **Подросток 14–16** — подростковые пропорции
- **Ребёнок 7–8 лет** — детский референс (полностью одетый)
- **Дошкольник 3–4 года** — toddler-пропорции

### Камера
4 объектива с конкретными параметрами:

- **120mm · Референс** — Phase One XF, без искажений, полный рост
- **85mm · Портрет** — Canon R5, f/1.8, shallow DOF
- **35mm · Кино** — Sony FX3, широкий план с окружением
- **200mm · Макс. резкость** — Nikon Z9, telephoto compression

### Фон
- **Белый** — чистый студийный бэкдроп
- **Серый** — нейтральный серый
- **Чёрный** — бесконечный чёрный фон
- **PNG** — полностью прозрачный фон
- **Градиент** — студийный светлый градиент

### Погода (слайдеры 0–10)
- **Мокрый** — от лёгкой влаги до полного намокания
- **Снег / иней** — от инея на волосах до ледяной скорлупы
- **Ветер** — от лёгкого бриза до штормовой силы
- **Пыль / грязь** — от пыли на ботинках до полного покрытия землёй

### Износ (слайдеры 0–10)
- **Поношенность** — от лёгких складок до «больше лоскутов, чем одежды»
- **Повреждения** — от мелких потёртостей до катастрофического разрушения

### SFX — Повреждения
Чипы для мульти-выбора эффектов спецэффектов. Каждый добавляет развёрнутое описание «film-grade SFX makeup»:

- Порез на лбу, синяк под глазом, кровь из носа, разбитая губа
- Гематома на щеке, заживший шрам, перевязанная рана
- Ожог на руке, ссадина на скуле, перелом носа
- Обморожение щёк, потрескавшиеся губы от мороза

### Настроение
14 эмоциональных состояний, каждое генерирует детальное описание мимики и позы:

- Нейтральный, грустный, гневный, испуганный, отчаянный
- Решительный, подавленный, растерянный, умоляющий
- Шок, замёрзший, изнурённый, радостный, гордый
- Нежный/тёплый, надежда/облегчение, лукавый/насмешливый, стоический

### Стиль (Nano Banana Pro)
- **RAW · без стилизации** — `--style raw`, минимальная обработка
- **RAW + stylize 0** — явный запрет любой стилизации
- **Stylize 200** — небольшая художественная свобода
- **Stylize 750** — сильная стилизация (⚠ может отойти от референса)

### Доп. текст
Свободное текстовое поле для любых дополнительных инструкций.

### Негативный промпт
Две группы чипов + контекстные чипы + ручное поле:

**Артефакты / качество:**
- Иллюстрация, аниме/мультфильм, стилизация, AI-кожа/CGI
- Зерно/ретро, широкий угол, размытие, вотермарк/текст, низкое качество

**Анатомия / содержание:**
- Деформации, руки/пальцы, обрезка фигуры, двойники/клоны
- Анахронизм, нагота

**Контекстные** — автоматически появляются при определённых настройках. Например: если выбран «Лунный свет» → появится чип «Тёплый свет · луна». Если выбраны 2+ ракурса → «Несоответствие ракурсов».

**«Выбрать все»** — кнопка с иконкой чекбокса выбирает/снимает все негативные чипы сразу.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl/Cmd + S` | Сохранить текущее состояние в Личное дело |
| `Ctrl/Cmd + Z` | Откат к предыдущему снапшоту в истории |
| `Ctrl/Cmd + Shift + Z` | Вперёд в истории |

(Внимание: горячие клавиши работают только когда фокус не в текстовом поле.)

## 📌 Система «Личное дело»

Сверху слева — селектор «Личное дело персонажа №». Это система пресетов:

1. **Создать новое дело** — введите имя в поле «+ Новое дело…» и нажмите «Завести» (или Enter). Текущие настройки сохранятся.
2. **Загрузить дело** — кликните на имя в выпадающем списке.
3. **Переименовать** — иконка ✎ рядом с именем в списке.
4. **Дублировать** — иконка ⎘ создаёт копию с суффиксом «· копия».
5. **Удалить** — иконка × рядом с именем.

**Авто-сохранение:** при изменении любого параметра текущее Дело автоматически получает пометку «несохранено» (пунктирное подчёркивание + звёздочка). Следующее сохранение перезапишет сохранённую версию.

**📌 Pin as preset** — кнопка в правой панели открывает селектор дел с уже заполненным именем, чтобы быстро сохранить текущее состояние.

---

## 📜 История изменений

Под правой панелью — горизонтальная полоса истории. Каждое изменение параметра создаёт снапшот (до 8 штук). Клик по снапшоту возвращает состояние на момент его создания.

Авто-снапшоты умные: если вы меняете параметры в одной секции, снапшот перезаписывается, а не создаётся новый. Новая секция — новый снапшот.

## 🔘 Кнопки правой панели

| Кнопка | Действие |
|--------|----------|
| ⎘⁺ | Копировать всё (промпт + негатив) |
| ⎘ | Копировать только промпт |
| ▪ | Переключить режим: подробный / краткий |
| ⏎ | Вкл/выкл перенос строк в выводе |
| 📌 | Сохранить как новое Личное дело |
| ↺ | Сбросить все настройки к дефолтным |
| ◉ лог | Скопировать лог взаимодействия за сессию |

## ⚠️ Известные ограничения

- Приложение рассчитано на Nano Banana Pro (Midjourney-подобный синтаксис `--ar`, `--style`, `--stylize`, `--q`). Для других генераторов промпт нужно адаптировать.
- Контекстные негативные промпты покрывают основные комбинации, но не все возможные.
- Пресеты хранятся в localStorage браузера — при очистке данных браузера они пропадут.
- Нет экспорта/импорта пресетов между устройствами.
- Один HTML-файл, ~180 КБ — всё работает в браузере, без сервера.
